# Capybar

A cozy card game set in a bar full of capybaras. Build the best table, combine abilities and out-score your rivals.

- Solo vs 1–3 bots, an interactive tutorial, and **online multiplayer** with friends (room code, peer-to-peer).
- Rules: see `Capybar_How_To_Play.pdf` or press **Rules** in the game.

## Play online with friends
One player presses **Play online → Host a game** and shares the 4-letter code (or the invite link). Friends press **Play online** and enter the code. Empty seats are filled with bots. The host's browser runs the game, so the host must keep the tab open.

Version 0.1 prototype: card values are still being tuned.
